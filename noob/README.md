# Panda Bamboo Dash

เกม Java Swing กระโดดเก็บไผ่ 3 ด่าน ใช้ `Graphics g`
โค้ดใช้ตัวแปร อาร์เรย์ ArrayList ลูป if และการสืบทอดคลาสพื้นฐาน ไม่มี HashMap

## เปิดเกม

เปิดโฟลเดอร์ `C:\Users\User\Desktop\New folder (2)` ใน VS Code
กด F5 แล้วเลือก Panda Bamboo Dash
ถ้าเพิ่งแก้โค้ด ให้ปิดหน้าต่างเกมเก่าแล้วรันใหม่

ไฟล์ตั้งค่าของเครื่องนี้ใช้ JDK ที่ `C:/Program Files/Java/jdk-26.0.1`
หากย้ายเครื่อง ให้แก้ `java.jdt.ls.java.home` ใน `.vscode/settings.json`

หรือคอมไพล์จากโฟลเดอร์โปรเจกต์ด้วย JDK 17 ขึ้นไป:

```powershell
javac --release 17 -encoding UTF-8 -d out/classes -sourcepath src src/Main.java
java -cp out/classes Main
```

## วิธีเล่น

- A/D หรือลูกศรซ้าย/ขวา ใช้เดิน
- W, ลูกศรขึ้น หรือ Space ใช้กระโดด ต้องปล่อยปุ่มก่อนกระโดดใหม่
- เก็บไผ่ 5 ชิ้นต่อด่าน ครบ 3 ด่านแล้วชนะ
- มีหัวใจ 4 ดวง ชนงูหรือตกหลุมเสีย 1 ดวง
- หลังเสียหัวใจ แพนด้ากระพริบและไม่เสียหัวใจซ้ำเป็นเวลา 1.4 วินาที
- Retry เริ่มใหม่พร้อมหัวใจ 4 ดวง Main Menu กลับเมนู

## เริ่มอ่านโค้ดตามลำดับนี้

1. `Main.java` สร้างหน้าต่าง แล้วนำ GamePanel ใส่ในหน้าต่าง
2. `GamePanel.java` รับปุ่ม เมาส์ และสั่งอัปเดตเกมจาก Timer ทุก 16 มิลลิวินาที
3. `Player.java` คำนวณเดิน กระโดด ตกลงพื้น เสียหัวใจ และกระพริบ
4. `Enemy.java` ขยับงูไปซ้ายขวา ชนขอบแล้วกลับทิศ
5. `Animation.java` นับเวลา แล้วเปลี่ยนหมายเลขภาพ
6. `Level.java` เก็บรายการพื้น งู และไผ่ แล้วเรียกวาดหรือตรวจชน
7. `Level1.java`, `Level2.java`, `Level3.java` กำหนดตำแหน่งสิ่งของของแต่ละด่าน
8. `Entity.java` เก็บ x, y, ความกว้าง ความสูง และเมธอดตรวจชนร่วมกัน
9. `Platform.java` วาดพื้นเป็นสี่เหลี่ยม
10. `Item.java` เก็บสถานะว่าเก็บไอเทมไปแล้วหรือยัง ถ้าเก็บแล้วไม่ต้องวาด
11. `Bamboo.java` กำหนดขนาดและรูปของไผ่ โดยใช้การเก็บไอเทมจาก Item
12. `Assets.java` โหลดภาพและเตรียมขนาดภาพครั้งเดียว
13. `UIManager.java` วาดปุ่ม เมนู หัวใจ และจำนวนไผ่
14. `GameState.java` รายชื่อสถานะ MENU, PLAYING, WIN, GAMEOVER

## คำที่พบในโค้ด

| คำ | ความหมายในเกมนี้ |
|---|---|
| `int` | จำนวนเต็ม เช่น จำนวนหัวใจ |
| `double` | จำนวนทศนิยม เช่น ตำแหน่งและเวลา |
| `boolean` | จริงหรือเท็จ เช่น ยืนบนพื้นหรือไม่ |
| `BufferedImage` | รูปภาพหนึ่งรูป |
| `BufferedImage[]` | อาร์เรย์ที่เก็บรูปหลายรูป |
| `ArrayList<Enemy>` | รายการงู ใช้ add เพิ่มงู แล้ววนลูปทีละตัว |
| `extends` | คลาสลูกใช้ข้อมูลหรือเมธอดของคลาสแม่ได้ |
| `super(...)` | เรียกตัวสร้างของคลาสแม่ |
| `@Override` | เมธอดที่เขียนแทนเมธอดเดิมของคลาสแม่หรือ interface |
| `implements KeyListener` | รับเหตุการณ์กดและปล่อยปุ่มผ่านเมธอดที่กำหนด |
| `static final` | ค่าคงที่ เช่น MAX_HEARTS = 4 |
| `dt` | เวลาที่ผ่านไปในการอัปเดตหนึ่งครั้ง หน่วยเป็นวินาที |

## อธิบายส่วนสำคัญ

### แอนิเมชัน

`pictures` คืออาร์เรย์รูป 4 รูป `pictureNumber` คือเลขรูปปัจจุบัน
บวกเวลาให้ `timer` ทุกครั้งที่อัปเดต เมื่อครบ `secondsPerPicture` ให้เลื่อนไปภาพถัดไป
ถ้า `repeat` เป็นจริง เมื่อถึงรูปสุดท้ายก็วนกลับรูปแรก
ท่ากระโดดไม่วนซ้ำ แต่ค้างรูปสุดท้ายจนกว่าจะลงพื้น

### เดินและกระโดด

เดินด้วยสูตร `x = x + velocityX * dt`
กระโดดโดยตั้งความเร็วแนวตั้งเป็นค่าลบ ทำให้ y ลดลง
ทุกครั้งที่อัปเดตจะเพิ่มความเร็วแนวตั้งจากแรงโน้มถ่วง ทำให้ตกลงมา
ตรวจชนแนวนอนก่อน แล้วจึงตรวจชนแนวตั้ง เพื่อแยกชนกำแพงออกจากลงพื้น

### กระพริบ

หลังเสียหัวใจจะตั้ง `damageCooldown` เป็น 1.4 วินาที
ระหว่างนี้ `blinkTimer` นับเวลา เมื่อครบ 0.1 วินาทีให้สลับ `hidden`
ถ้า `hidden` เป็นจริง จะข้ามการวาดรูป เมื่อหมดเวลาป้องกันให้แสดงตัวตลอดตามปกติ

### ภาพและพิกัด

การเดินกับการชนใช้พิกัด 800 x 600 ตามเดิม
`screenX` และ `screenY` แปลงพิกัดตอนวาดลงหน้าจอ 1280 x 720
`Assets` ย่อรูปอย่างนุ่มนวลครั้งเดียวก่อนใช้ เพื่อไม่ให้ภาพแตกจากการย่อซ้ำ
ส่วนค้นหาโฟลเดอร์ assets และตัดภาพโปร่งใสเป็นส่วนช่วยโหลดภาพ ไม่ได้ควบคุมการเล่น

## โฟลเดอร์

- `src` คือโค้ดเกมที่อ่านและแก้ไข
- `assets` คือรูปภาพของเกม
- `.vscode` คือการตั้งค่า F5
- `.idea` คือการตั้งค่า IntelliJ
- `out/classes` คือไฟล์ที่คอมไพล์แล้ว ใช้เปิดเกม
- `tests` คือชุดตรวจการทำงาน แยกจากโค้ดเกม
- `backups` คือไฟล์ก่อนแก้ไข ไม่ถูกนำมาคอมไพล์หรือรัน
